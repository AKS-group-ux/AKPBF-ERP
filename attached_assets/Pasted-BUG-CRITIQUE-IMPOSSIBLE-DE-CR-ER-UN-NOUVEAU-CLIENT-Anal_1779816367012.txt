BUG CRITIQUE : IMPOSSIBLE DE CRÉER UN NOUVEAU CLIENT

Analyse l'intégralité du système d'authentification, d'inscription et de création des clients.

OBJECTIF

Identifier précisément pourquoi la création d'un nouveau client échoue et corriger définitivement le problème.

==================================================
ANALYSE COMPLÈTE
==================================================

Vérifier :

1. Frontend
- formulaire d'inscription
- validation des champs
- envoi des données API
- gestion des erreurs
- affichage des messages

2. API Backend
- route register
- route create client
- route create user
- permissions
- middlewares

3. Base PostgreSQL
- contraintes
- colonnes obligatoires
- clés étrangères
- index
- valeurs nulles interdites

==================================================
POINTS À VÉRIFIER
==================================================

Vérifier notamment :

- email déjà existant
- téléphone déjà existant
- mot de passe invalide
- rôle client inexistant
- utilisateur créé mais client non créé
- client créé mais utilisateur non créé
- transaction interrompue
- erreur JWT
- erreur CORS
- erreur validation backend
- erreur SQL
- erreur de migration
- erreur de relation entre tables

==================================================
LOGGING
==================================================

Ajouter temporairement des logs détaillés :

- données reçues
- validation
- création utilisateur
- création client
- création contrat
- création abonnement
- réponse API

==================================================
TRANSACTION
==================================================

La création d'un client doit être atomique :

1. créer utilisateur
2. créer client
3. associer rôle
4. créer abonnement si nécessaire
5. valider transaction

Si une étape échoue :

ROLLBACK COMPLET

==================================================
RÉSULTAT ATTENDU
==================================================

Produire un rapport :

AUTHENTICATION_BUG_REPORT.md

contenant :

- cause exacte du problème
- fichier concerné
- ligne concernée
- correction appliquée
- test effectué

Puis corriger le problème.
