- Odoo Enterprise
- Linear
- Notion
- Stripe Dashboard
- Microsoft Fluent Design

==================================================
ANALYSE COMPLÈTE DE L'INTERFACE
==================================================

Inspecter toutes les pages :

- Login
- Dashboard Admin
- Dashboard Client
- Contrats
- Abonnements
- Factures
- Paiements
- Collectes
- Comptabilité
- Paramètres

Identifier :

- problèmes d'alignement
- problèmes responsive
- tailles de police incohérentes
- composants mal dimensionnés
- mauvaises marges
- mauvais espacements
- icônes mal positionnées
- contrastes insuffisants
- incohérences visuelles

Corriger tous les problèmes détectés.

==================================================
PAGE DE CONNEXION
==================================================

Refondre entièrement la page Login.

Objectifs :

- design premium
- responsive mobile/tablette/desktop
- lisibilité parfaite
- cohérence visuelle

==================================================
ALIGNEMENT DES CHAMPS
==================================================

Corriger tous les problèmes d'alignement.

Les icônes doivent être parfaitement centrées verticalement.

Le texte saisi doit être parfaitement aligné avec les icônes.

Les placeholders doivent être centrés correctement.

Aucun texte ne doit apparaître plus bas ou plus haut que les icônes.

Utiliser flexbox correctement :

align-items: center

Vérifier tous les champs du projet.
